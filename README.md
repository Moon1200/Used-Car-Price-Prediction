# تحليل وفحص بيانات السيارات المستعملة في السعودية
Used Cars Price Analysis & Prediction in Saudi Arabia

مشروع تحليلي متكامل يتكون من عدة مراحل تهدف إلى استكشاف، تنظيف، وتحليل سوق السيارات المستعملة في المملكة العربية السعودية باستخدام Python، SQL، و Power BI.


مراحل المشروع الأساسية:

المرحلة الأولى: بايثون (Python - Statistical Analysis & Modeling)
تم استخدام بايثون في هذا المشروع لتنفيذ التحليل الإحصائي واختبارات الفرضيات وتدريب نموذج الانحدار الخطي المتعدد (Multiple Linear Regression - OLS Model) لمعرفة العوامل المؤثرة على السعر.
- الأدوات والمكتبات المستخدمة: Pandas, SciPy (لإجراء اختبارات T-test و ANOVA), Statsmodels.
- أبرز ما تم تنفيذه في الكود:
  1. اختبار الفروق الإحصائية بين أسعار السيارات ذات القير الأوتوماتيكي والعادي (Independent T-Test).
  2. اختبار تأثير مناشئ السيارات (Origin: Saudi, Gulf Arabic, Other, Unknown) باستخدام (ANOVA F-Test).
  3. بناء نموذج الانحدار الخطي (`statsmodels.formula.api`) لأهم 8 ماركات سيارات لتوقع الأسعار ومعاملات التأثير (R-squared = 0.506).
  4. تصدير معاملات النموذج إلى ملف (car_price_coefficients.csv).


المرحلة الثانية: قاعدة البيانات واستعلامات SQL (SQL Analysis)
بعد تنظيف البيانات المبدئي، تم رفعها لبيانات SQL لتنفيذ عمليات التصفية المتقدمة واستخراج الرؤى (Insights).
عند فحص عمود السعر (Price)، تبيّن أن 2,527 سيارة (31% من إجمالي البيانات) مسجلة بسعر صفر.
بربطها بعمود Negotiable، اتضح أن 2,526 منها (99.96%) هي سيارات "قابلة للتفاوض" ولم يحدد لها البائع سعراً ثابتاً.
تم استبعاد هذه الصفوف بالكامل لتفادي تشويه المتوسطات والتحليلات الإحصائية.


أبرز الاستعلامات المنفذة والموجودة في ملف (queries.sql):
1. فحص القيم الصفرية: الكشف عن الارتباط بين الأسعار الصفرية وحالة التفاوض.
2. تنظيف الجدول (clean_cars): استبعاد الأسعار الصفرية وحذف التكرارات (DISTINCT).
3. أعلى السيارات سعراً: استخدام دالة RANK() لإيجاد أغلى 3 سيارات لكل ماركة.
4. المتوسط المتحرك (Moving Average): تتبع تطور متوسط الأسعار عبر السنوات.
5. النسبة المئوية الإقليمية: حساب حصة كل ماركة سيارة من إجمالي السيارات في كل منطقة.
6. التوزيع السعري (Quartiles): استخدام NTILE(4) لتوزيع الأسعار إلى أرباع لكل ماركة.


المرحلة الثالثة: لوحة المؤشرات (Power BI Dashboard)
تم ربط البيانات النظيفة ببرنامج Power BI لتصميم لوحة تحكم تفاعلية (Interactive Dashboard) تعرض:
- متوسط الأسعار حسب الماركة والموديل والمنطقة.
- تأثير سنة الصنع وعداد المسافات (Mileage) على السعر.
- مؤشرات أداء رئيسية (KPIs) تسهل على المستهلك والمشتري اتخاذ القرار.
